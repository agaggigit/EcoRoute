## Project Senior Project TI

- **Nama Aplikasi:** EcoRoute
- **Kategori:** Climate Action / Carbon Footprint Tracker
- **Tipe Aplikasi:** Aplikasi Desktop Windows yang dikembangkan dengan bahasa C# menggunakan framework Windows Presentation Foundation (WPF) dengan UI berbasis XAML.

## Permasalahan yang dipecahkan:
1. Kurangnya Kesadaran Emisi Pribadi: Komuter harian tidak memiliki
visualisasi nyata mengenai seberapa besar volume jejak karbon (CO₂) yang
mereka kontribusikan ke atmosfer dari rute perjalanan harian mereka.
2. Dampak Tersembunyi Kemacetan Lalu Lintas: Pengendara sering
mengabaikan fakta bahwa durasi macet (idling engine atau stop-and-go)
meningkatkan konsumsi bahan bakar dan emisi karbon secara eksponensial
dibandingkan kondisi jalan lancar.
3. Keterbatasan Visualisasi Komparatif yang Praktis: Belum ada aplikasi
desktop Windows yang memudahkan pengguna melakukan simulasi rute
secara lokal dan membandingkan dampak lingkungan antar berbagai moda
transportasi secara berdampingan dalam satu layar.

## Solusi yang diusulkan beserta fitur aplikasi: 
Sebuah aplikasi dashboard desktop Windows (WPF) yang berfungsi sebagai simulator rute ramah lingkungan. Aplikasi ini memproses data rute nyata dari Google Maps API secara real-time, lalu menghitung serta menampilkan perbandingan emisi karbon antarmoda secara dinamis di layar komputer.

## Aplikasi Sejenis yang mirip:
1. Google Maps (Versi Web/Mobile): Menyediakan fitur rute hemat bahan
bakar (daun hijau), namun tidak tersedia sebagai aplikasi desktop Windows
native dan tidak menyajikan grafik komparatif emisi antarmoda yang
mendalam secara berdampingan.
2. Sistem Dashboard Logistik Enterprise (Fleet Management Desktop):
Aplikasi desktop yang menghitung emisi karbon untuk armada truk
perusahaan, namun bersifat berbayar mahal, privat, dan tidak ditujukan untuk
komuter transportasi publik masyarakat umum.
3. Kalkulator Karbon Statis (Situs Web): Mampu menghitung emisi karbon,
tetapi bersifat statis karena pengguna harus memasukkan jarak dalam angka
secara manual, serta tidak terintegrasi dengan peta visual maupun kondisi
kemacetan lalu lintas jalan raya yang berubah-ubah.
